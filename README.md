# Moe Abo Sen — My Portfolio

A responsive portfolio built with HTML, CSS, and JavaScript for GitHub Pages.

## Publish

1. Create a public repository named `My-Portfolio` under `mohammed-naji26`.
2. Upload all extracted files directly to the repository root and commit them to `main`.
3. Open **Settings → Pages** and select **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Open `https://mohammed-naji26.github.io/My-Portfolio/` after deployment finishes.
